How to subscribe

Outlook on the web: Calendar → Add calendar → Subscribe from web → paste the URL.
Outlook desktop: Account Settings → Internet Calendars → New.
Google Calendar: Other calendars → + → From URL → paste the URL.
Entries are all-day and marked free, so they never block your availability.
